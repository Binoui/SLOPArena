# Move illustrations

These 47 original imagegen illustrations are shipping UI assets, with matching
Unity importer metadata. Each PNG embeds its exact generation prompt as
`impeccable:prompt`. They use the fighter's presentation identity and carry no
gameplay authority. The HUD keeps a fixed grounded icon legend; authored air
variants remain available as assets.

Keep source PNGs and `.meta` files together. Preserve alpha and the current
sprite import settings. Generation queues, local source paths, mockups and review
captures stay outside Git. This folder contains no vendor animation or model
source. See the [visual contract](../../../../../../DESIGN.md).
