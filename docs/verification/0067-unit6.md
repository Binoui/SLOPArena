# ADR-0067 unit 6 verification

Players can make fighters and play them through the same package path as built-ins. This refactor removes the selector enum from internal identity. The enum is private to `LegacyFighterProtocol`. It retains the seven online selector spellings and rejects numeric strings, including retired value 5.

## Changes

- Catalogs resolve by package or match-local handle. Definitions derive their package ID from cooked metadata. Admitted fighters and choices carry no selector field. The runtime adapter accepts no selector parameter.
- Mayhem guests, Tutorial dummies, Arcade tools, CPU profiles and reports name packages when deliberately choosing a built-in fighter.
- Presentation and menus read package identity. The renderer's fallback animation configuration uses the model binding path.
- Tests and tools use package IDs. `RosterFighters` enumerates package requirements from the cooked roster.
- Hurtbox sidecars read legacy names and package IDs, write package IDs, and reject numeric strings and retired names. The roster compatibility adapter preserves defaults when a stored selector names a package alias. Training metadata tests translate historical names at their read boundary.

## Guard

`python3 tools/check_fighter_identity.py` scans tracked and unignored C# source. Only `src/Shared/LegacyFighterProtocol.cs` may reference the enum. A planted reference in `src/Shared/Unit6GuardProbe.cs` failed with exit 1; removing the probe passed. `FighterIdentityBoundaryTests` invokes the same guard and tests old names, package IDs, numeric rejection and hurtbox writing.

## Refactoring choices

Model the Domain put package identity directly on runtime definitions. Migrate Callers Then Delete Legacy APIs removed selector-bearing overloads with their callers. Laziness Protocol removed the duplicate selector dictionary rather than adding a second identity wrapper. Build the Lever produced the census and source guard. Prove It Works prevented claiming presentation equivalence after the cook gate failed.

## Phase 3

Replace Room choices, launch selectors, schema 2 online handle maps and the Master's roster list together with a protocol bump. Delete `LegacyFighterProtocol` and its online callers in that release. Keep readers for persisted historical names where old stored data remains supported.
